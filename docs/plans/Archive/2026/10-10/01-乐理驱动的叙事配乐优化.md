# 乐理驱动的叙事配乐优化

设计边界见[叙事配乐 · 编曲依据与当前取舍](../../../../story-scoring.md#编曲依据与当前取舍)。[^design] 本计划把乐理检查落到现有确定性编曲器。

## Context

原故事编曲器以固定中心音区独立选音，并在每组第四音抬高参考音区，造成分解和弦的突兀大跳；钢琴和尼龙吉他使用同一种分解模式，多件木管也同拍重复回答。已检索并阅读 music-composition skill 的声部连接、编曲密度和再和声章节，并用 Open Music Theory 交叉核对。[^theory]

## Approach

复用 `voice` 的音高候选选择和现有 `previous` 声部状态，按设计中的音区限制连接分解和弦。对答声部从尚未退场的乐器中轮换；示例吉他使用已有的 `color` 职责。两项回归分别覆盖整曲伴奏跳进和多个对答声部的轮换、退场。

## Scope

- In: `src/story/compose.py` 的分解和弦连接及对答轮换；示例吉他角色；回归测试、理论来源与试听产物。
- Out: 新和弦库、自动和声重写、真实采样演奏法、混音 EQ 和母带参数。

## Verification

本机实际使用 `/tmp/musician-assessment.GAJmto/venv/bin/python` 执行测试与渲染：45 项测试通过，日志为 `/tmp/musician-theory-research/tests.log` 与 `render.log`。以下命令可在安装 uv 的环境复现，渲染默认创建独立输出目录。

```bash
uv run --frozen python -m unittest discover -s tests -v
uv run --frozen musician story examples/originally-you.json --fallback
ffprobe -v error -show_entries format=duration:stream=sample_rate -of json out/story/originally-you-theory/final.wav
```

本次产物在 `out/story/originally-you-theory/`：58 小节、23 声部、1,016 个音符，48 kHz 双声道、185.999979 秒、−18 LUFS、峰值 −4.16 dBFS。FFmpeg 完整解码 MP3 成功；`verification.json` 记录乐谱与音频测量。

与上版相比，连续伴奏（前后音起点间隔不超过 4.01 拍）的最大跳进：钢琴 22→8 半音，竖琴 20→9 半音；八度及以上跳进分别由 54、31 次减为零。吉他音符由 84 个减为 11 个，安宁段木管最大同时进入数由 3 减为 1。已断言主题、和弦和时间线一致，分解和弦音都属于当前和弦。

`compare-v2-theory.mp3` 为开头等响度对比：0–20 秒为上版，20–21 秒静音，21–41 秒为本版，两段均为 −20 LUFS。使用同一草稿音源比较编曲；真实采样音色与人工试听仍待验收。本轮未重新生成完整视频。
